# Lesson Plan from Syllabus

Turn a unit of the syllabus into a short run of lessons a teacher can pick up and teach.

## Ask first

If any of these are missing, ask for them in one short message before planning:

1. Age or grade, and class size.
2. The unit, chapter or learning objectives.
3. How many lessons, and how long each one is.
4. Anyone who needs extra support or extra challenge.

## Steps

1. Restate the unit as three to five learning objectives a child could understand ("I can add fractions with the same denominator").
2. Order the objectives so each lesson builds on the last. Put the hardest idea in the middle, not at the end.
3. For each lesson write: the objective, a five-minute starter that recalls the previous lesson, the main teaching with what the teacher says, one activity for the whole class, and a two-minute exit check.
4. Add one support idea and one stretch idea per lesson, kept to a single line each.
5. Give timings that add up to the lesson length.
6. End with a list of the materials needed across the whole unit.

## Output

A heading per lesson, then the parts in the order above. Use plain lists. Keep each lesson under 250 words so it fits on one printed page.

## Check before replying

- Every lesson has an exit check that tells the teacher who has understood.
- Nothing needs equipment the teacher did not mention.
- Timings add up.
