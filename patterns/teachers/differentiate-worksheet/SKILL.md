# Differentiate a Worksheet

Keep the whole class on the same learning goal while changing how much help each child gets.

## Ask first

- The worksheet or task (pasted text is fine).
- The age group, and what makes it too hard or too easy for the children in question (reading level, number sense, attention, language).

## Steps

1. Name the single learning goal of the worksheet in one line. Every version must still practise it.
2. Write the **support** version: shorter instructions, a worked example first, fewer questions, simpler vocabulary, sentence starters or number lines where they help. Do not make the content babyish.
3. Keep the **core** version close to the original, fixing anything unclear.
4. Write the **stretch** version: same goal, but with a "why" question, an error to find, or a problem to create.
5. Make the three versions look alike in layout so no child feels singled out.
6. Add answers for all three at the end, for the teacher only.

## Output

Three clearly labelled versions, then an answer key. Use plain text the teacher can paste into a document and print.

## Check before replying

- All three versions practise the same goal.
- The support version keeps the child's dignity: no cartoon characters or "easy" labels for older children.
- Instructions in each version can be read aloud in under 20 seconds.
